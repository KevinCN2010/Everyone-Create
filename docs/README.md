## 🤝 协作信息

### 协作方式

- **提 PR** — Fork 本仓库，修改对应文档后提交 Pull Request
- **提 Issue** — 直接发 Issue，带上 `question` 标签
- **群聊反馈** — 在任意聊天频道 @管理员 反馈

### 文档审校

开放部分文档区域供社区成员共同审校与修改，审核通过后合并。

### 贡献名单

所有贡献者会在 [贡献名单](https://www.eocc.top/marker/) 永久留名。
