核心功能

流量趋势

按日采集访问量与克隆量并保留历史曲线，弥补 GitHub 仅保留 14 天数据的限制。

仓库深度浏览

提交、Issue、Pull Request、发布与源码目录，无需跳转 GitHub 即可查阅详情。

多 Token 调度

按剩余配额自动选择 Token，耗尽时自动切换，并提供实时用量统计。

趋势预测

基于历史流量数据训练模型，预测未来的访问与克隆走势。

插件系统

功能以插件形式按需启用，可按仓库限定作用域，互不干扰。

多语言与主题

简体中文、繁體中文与英文三语切换，深浅色主题与多种配色可选。
